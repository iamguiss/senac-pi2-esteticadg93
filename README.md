# senac-pi2-esteticadg93

## Estética DG93 — Sistema de Gestão e Agendamento

Projeto Integrador do SENAC desenvolvido para a Estética DG93, com foco no desenvolvimento de um sistema web para facilitar o agendamento de serviços, a consulta de informações e a organização dos atendimentos entre clientes e empresa.

## Objetivo

Desenvolver uma aplicação web que permita aos clientes consultar serviços, valores e horários disponíveis, realizar e acompanhar agendamentos, além de auxiliar a Estética DG93 no gerenciamento de seus serviços e atendimentos.

## Estrutura do projeto

```text
backend/    → desenvolvimento do back-end
frontend/   → desenvolvimento da interface
database/   → arquivos relacionados ao banco de dados
docs/       → documentação do projeto
.github/    → configurações do GitHub e Issues

## Público-alvo

Clientes da Estética DG93 e o responsável pelo gerenciamento dos atendimento

## Principais funcionalidades

- Consulta de serviços e valores
- Cadastro e login de clientes
- Agendamento de serviços
- Consulta e acompanhamento de agendamentos
- Cancelamento e solicitação de reagendamento
- Gerenciamento de serviços e agendamentos pelo administrador

## Como executar

1. Instale o XAMPP.
2. Inicie o Apache e o MySQL.
3. Coloque o projeto na pasta `htdocs`.
4. Crie o banco de dados utilizando o arquivo `database/database.sql`.
5. Acesse o projeto pelo navegador através do `localhost`.
