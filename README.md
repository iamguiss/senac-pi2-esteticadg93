# senac-pi2-esteticadg93

## Estética DG93 — Sistema de Gestão e Agendamento

Projeto Integrador do SENAC desenvolvido para a Estética DG93, com foco no desenvolvimento de um sistema web para facilitar o agendamento de serviços, a consulta de informações e a organização dos atendimentos entre clientes e empresa.

## Objetivo

Desenvolver uma aplicação web que permita aos clientes consultar serviços, valores e horários disponíveis, realizar e acompanhar agendamentos, além de auxiliar a Estética DG93 no gerenciamento de seus serviços e atendimentos.
