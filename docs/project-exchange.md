# Atividade 03 — Troca de Feedback entre Projetos

## Objetivo

A atividade teve como objetivo promover a troca de experiências entre os grupos, permitindo conhecer diferentes projetos, compartilhar feedbacks e identificar ideias que pudessem contribuir para a evolução do projeto Estética DG93.

## Projetos visitados

### Projeto 1 — Sistema de Agendamento para Barbearia

**Ponto positivo:**  
O projeto apresentou um fluxo de agendamento simples e fácil de entender, com poucas etapas para realizar uma reserva.

**Sugestão de melhoria:**  
Adicionar informações mais detalhadas sobre o serviço escolhido antes da confirmação do agendamento.

**Pergunta:**  
Como o sistema pretende evitar conflitos quando dois usuários tentarem agendar o mesmo horário?

### Projeto 2 — Sistema de Gestão para Restaurante

**Ponto positivo:**  
O projeto apresentou uma organização clara das informações e uma separação bem definida entre as funcionalidades do usuário e do administrador.

**Sugestão de melhoria:**  
Melhorar a visualização dos status das operações para facilitar a identificação de situações pendentes ou concluídas.

**Pergunta:**  
Como o administrador poderá acompanhar as alterações realizadas pelos usuários no sistema?

### Projeto 3 — Plataforma de Serviços

**Ponto positivo:**  
O projeto apresentou uma boa organização das categorias e facilitou a busca pelos diferentes serviços disponíveis.

**Sugestão de melhoria:**  
Adicionar filtros para facilitar a localização de serviços específicos.

**Pergunta:**  
Como os usuários poderão acompanhar o andamento de uma solicitação depois de realizá-la?

## Feedbacks recebidos

Durante a troca entre os grupos, o projeto Estética DG93 recebeu feedbacks relacionados principalmente à organização do processo de agendamento e à apresentação das informações dos serviços.

**Ponto positivo:**  
A divisão entre área do cliente e área administrativa foi considerada clara e adequada para o funcionamento da Estética DG93.

**Sugestão de melhoria:**  
Deixar mais evidente para o cliente o status do agendamento após a solicitação, permitindo que ele saiba se o pedido está aguardando confirmação, aprovado ou negado.

**Observação:**  
Também foi sugerido apresentar as principais informações do serviço durante o processo de agendamento, reduzindo a necessidade de retornar à página de serviços.

## Ideia escolhida

A ideia escolhida foi **melhorar a visualização do status dos agendamentos para o cliente**.

## Como a ideia será aplicada

A melhoria será aplicada na área do cliente, utilizando indicadores visuais para apresentar claramente o estado de cada agendamento.

Os principais estados considerados serão:

- Aguardando confirmação;
- Aprovado;
- Negado;
- Em andamento;
- Concluído;
- Cancelado.

Dessa forma, o cliente poderá acompanhar o andamento do seu agendamento sem precisar entrar em contato diretamente com a empresa.

## Melhoria implementada ou planejada

**Status: Planejada**

A melhoria será incorporada ao sistema durante a implementação das funcionalidades de agendamento e integração com o PHP e o banco de dados.

Além da identificação textual do status, serão utilizados componentes visuais padronizados para facilitar a compreensão das informações.
